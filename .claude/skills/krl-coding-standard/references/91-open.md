# 3. アンチパターン集

既存コードで実際に起きた失敗。レビュー時のチェックリストとして使う。

## 3-A. 動作パラメータ

- **CP パラメータ未設定のまま `LIN` を実行。** `MotionPar(#CPmotion,…)` を
  呼ばず `$VEL.CP` が初期値のまま。T1 では速度クランプで隠れ、AUTO で
  A4 速度超過により停止（DryRun_20260915）
- **サブプログラムに INI フォールドが残り**、呼ぶたびに
  `BAS(#INITMOV,0)` が動作パラメータをリセット（UEC `arcon_ohta`）
- **`MotionPar` の1回呼び。** ブロック選択で途中から流すと TOOL/BASE すら
  未設定になる

## 3-B. 単位と型

- **同じ概念に別名・別単位。** `TS`（mm/min）と `Velocity`（m/s）が同居
- **`:IN` 引数を書き換えて単位を変える。** `Velocity = VelocityCalc(Velocity)`
  の前後で物理量が変わる
- **モードで引数の単位が変わる関数。** `MotionPar` は `#PTPmotion` なら %、
  `#CPmotion` なら m/s
- **`REAL` を `INT` 引数に渡す。** 黙って四捨五入される

## 3-C. 状態と重複

- **データの形から状態を逆算する。** `IF WV_SEG2.Y <> 0.0` で進行方向を
  判定し、X進行モードで誤判定。ELSE が到達不能（WVBead `SegFlip`）
- **死んだ分岐。** `VelocityCalc` の IF と ELSE が同一式
- **コピペ後の改変が追跡できない。** 同じ関数が11ファイルにあり、
  ELSE の値だけファイルごとに違う
- **パラメータを処理部に直書きし、条件違いでファイルごと複製。**
  `CircD2015_10RadiusChange01.src` が無印版と diff 完全一致
- **`.dat` を実行時に書き換え、終了時に戻さない。** `BASE_DATA[17]` の上書き

## 3-D. 静かな失敗

- **ゼロ長動作。** `LIN_REL START_OFS` で `SX=SY=SZ=0`
- **空の IF ブロック。** 中身がコメント1行のみ
- **`.dat` の未初期化宣言。** 初期化処理を飛ばすと前回の値で動く
- **`;ENDFOLDEND`。** `;ENDFOLD` と `END` が連結してフォールドが閉じない
- **呼び名と実体の不一致。** `coordinate()` を呼ぶが実体は `coordinate_ohta.src`
- **未使用変数。** UEC の `weld_*` 8個中4個が未使用

## 3-E. 検証

- **T1 で動いたことを AUTO の検証と見なす**
- **他プログラムから S/T をコピーする**
- **「全プログラムで使われていない」と断定する。** `$OUT` は SPS.SUB や
  PLC からも立てられるので、`.src` を全部読んでも証明にならない
